## ما نُفذ

1. مقارنة كل الملفات، وحفظ النسخ، وفحص SHA-256 وصياغة ملفات PHP قبل التفعيل.
2. تثبيت وتشغيل الهجرة المحددة فقط:

```sh
php artisan migrate --path=database/migrations/2026_11_08_100000_create_vendor_invoice_templates_table.php --force
```

3. تفعيل ملفات الميزة وحدها، مع نقل الملفات الجديدة أولًا قبل ربط المسارات والواجهات.
4. مسح كاش المسارات وتجميع Blade بنجاح. لم يكن كاش المسارات مفعّلًا قبل النشر، وبقي كذلك.
5. لا Composer install، ولا DatabaseSeeder، ولا إعادة إعداد Passport أو OTP أو تغيير أدوار المستخدمين.

## نتائج الإنتاج

- بصمات الملفات الستة عشر طابقت الحزمة المنشورة.
- عبر Laravel HTTP kernel باستخدام هويات المستخدمين المرتبطين بالمتجرين 3 و6: المحرر والمعاينة يُعيدان HTTP 200.
- النسخ normal/customer/store أعادت HTTP 200 للطلبات الحقيقية المختبرة، مع بيانات وإعدادات متطابقة ومبلغ إجمالي مطابق للطلب المحفوظ. شملت الطلبين 37 و41 دون تعديلهما.
- منع صاحب المتجر الآخر من الطباعة ومعاينة الطلب بإرجاع 404؛ منع العميل من المحرر والطباعة بإرجاع 403.
- استطاع root طباعة الفاتورة، ولم يسمح له محرر المالك بتعديل قالب متجر آخر.
- اختبار الحفظ والاسترجاع في MySQL نُفذ داخل معاملة خارجية أُلغيت بالكامل بعد نجاحه. لم يبق أي إعداد تجريبي محفوظ، ولم تُرفع شعارات اختبارية على الإنتاج.
- تطابقت بصمات جداول `orders`, `order_products`, `vendors`, `users`, `role_has_permissions`, `model_has_permissions`, `oauth_clients` قبل التفعيل وبعد الفحوص. بقيت الطلبات وأسعارها والمستخدمون والصلاحيات وبيانات عميل Passport كما كانت.
- فحص HTTPS الخارجي: صفحة الدخول و`GET /api/vendors` وملفات JS/CSS الأربعة HTTP 200؛ المحرر والفاتورة لغير المسجلين HTTP 302 إلى المصادقة.
- لم تزد أخطاء Laravel بعد تفعيل الميزة: بقي حجم السجل 261295 بايت أثناء فحوصها. الزيادة السابقة عن 261039 كانت خطأ محاولة النسخ الأول المذكور أعلاه.
- أُزيلت ملفات النشر المؤقتة من `/tmp`، وبقيت النسخ الاحتياطية خارج المسار العام.

اختبارات التطوير السابقة للنشر: 287 اختبار Laravel و1396 تحققًا، إضافة إلى 43 تحققًا في Chromium. التحقق الإنتاجي المصادق عليه تم عبر kernel، وليس جلسة متصفح فعلية. الطابعات الحرارية الفعلية لا تزال تحتاج ضبط المقاس والهوامش في تعريف الطابعة.
